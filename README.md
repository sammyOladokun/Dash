# Northstar — Personal OS

A browser-based personal dashboard prototype.

## Requirements

- Node.js 20.19+ (or 22.12+)
- npm 10+

## Start the development server

```sh
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Production build

```sh
npm run build
npm run preview
```

The production files are written to `dist/`. The app currently uses illustrative demo data and browser-side interactions; it has no database or external account integrations yet.
